# Changelog

All notable changes to `@bymax-one/nest-telemetry` are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Until an API is declared stable, a version number is not a compatibility promise: breaking
changes can ship in a minor or patch release, and the migration note of each release carries
the compatibility information.

The `release.yml` workflow extracts the section matching the pushed `vX.Y.Z` tag
as the GitHub Release body, so each released version needs a matching `## [X.Y.Z]`
heading here.
